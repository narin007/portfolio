ESP32 · FreeRTOS · STATE MACHINE · FOOD PROCESSING

Non-Blocking Control Architecture

Real-time safe
Two FreeRTOS tasks — the real-time control loop never waits on the background cloud-log transmit.

Problem

Cloud logging on a food-processing controller competes with the control loop — a blocking transmit means a missed real-time deadline on live equipment.

Approach

Built the controller on ESP32 + FreeRTOS with data transmission isolated as a separate background task, applying state-machine design, ISRs and hardware debouncing; HMI integrated with relay boards over Modbus RS485 on an isolated control LAN.

Result

Cloud logging never interrupts real-time loops — telemetry without trading away deterministic control.
